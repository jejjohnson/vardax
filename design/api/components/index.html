MaskedIdentity, LinearObs, and AveragingKernel satisfy pipekit_cycle.ObservationOperator directly. MultiInstrumentFusion returns dict[str, Array] natively and exposes a .to_observation_operator() adapter (block-diagonal flattening) for strict-protocol contexts.

Gradient modulators (vardax.grad_mod — FourDVarNet only)¶

The grad modulator family is FourDVarNet-specific. Classical methods (OptimalInterpolation, ThreeDVar, StrongFourDVar, WeakFourDVar, IncrementalFourDVar) use optimistix.AbstractMinimiser instead of a learned inner step.
