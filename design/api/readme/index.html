vardax — API Overview

Complete inventory of the vardax public surface, organised by layer and by protocol family. v0.4 changes the Layer 2 surface to seven peer classes (Decision D14) and replaces the grad_mode enum with adjoint slots from optimistix / diffrax (Decision D15).

Layer map¶

  • Layer 0 — Primitives — Layer 0: pure JAX cost functions, closed-form BLUE, CVT, Laplace covariance, adjoint passthrough.

  • Layer 1 — Components — Layer 1: protocols (Prior, GradModulator, CostFunction, PosteriorAdapter, Minimiser) + concrete implementations. Pipekit-cycle protocol re-exports.

  • Layer 1 — Observation Operators — Layer 1 observation operator family: MaskedIdentity, LinearObs, AveragingKernel, MultiInstrumentFusion, InstrumentRegistry.

  • Layer 2 — Models — Layer 2: the seven peer analysis classes.

Adjoint slots (v0.4 — Decision D15)¶

Models that involve dynamics or inner minimisation carry adjoint constructor slots passed straight through to the upstream library:

SlotTypeUsed byDefault
checkpointbool | intStrongFourDVar, WeakFourDVar, IncrementalFourDVar, ReducedBasisFourDVarFalse
forward_adjointdiffrax.AbstractAdjoint, applied via forward.with_adjointthe same fourNone (forward’s own)
minimiser_adjointoptimistix.AbstractAdjointThreeDVar, StrongFourDVar, WeakFourDVarImplicitAdjoint()
solver_adjointoptimistix.AbstractAdjointFourDVarNet (through the learned inner solver)RecursiveCheckpointAdjoint()

The Bolte 2023 one-step method appears as vardax.adjoints.OneStepAdjoint, an optimistix.AbstractAdjoint subclass targeting upstream contribution.
