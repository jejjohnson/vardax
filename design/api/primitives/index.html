Layer 0 — Primitives

Pure JAX functions. Stateless, differentiable, no eqx.Module, no optimistix. The mathematical building blocks that Layer 1 operators compose.

v0.4 removes the in-house gradient-mode primitives (unrolled_solve, one_step_solve, implicit_solve) in favour of upstream optimistix.AbstractAdjoint and diffrax.AbstractAdjoint (Decision D15). The remaining primitives are mathematical, not differentiation strategies.

Cost terms¶

obs_cost(x, y_obs, mask, obs_operator=None, R_inv_op=None)¶

Observation cost:

Jobs(x)=12∥H(x)−y∥R−12.J_\text{obs}(x) = \tfrac{1}{2} \|H(x) - y\|^2_{R^{-1}}.Jobs​(x)=21​∥H(x)−y∥R−12​.
(1)

When obs_operator=None, HHH defaults to masked identity. When R_inv_op=None, R−1R^{-1}R−1 defaults to I/∣Ω∣I / |\Omega|I/∣Ω∣ (averaged MSE).

prior_cost(x, prior_mean=None, B_inv_op=None, prior_fn=None)¶

Two distinct meanings depending on which kwargs are passed:

Classical (prior_mean and B_inv_op supplied):

Jprior(x)=12∥x−xb∥B−12.J_\text{prior}(x) = \tfrac{1}{2} \|x - x_b\|^2_{B^{-1}}.Jprior​(x)=21​∥x−xb​∥B−12​.
(2)

Learned (prior_fn supplied — FourDVarNet):

Jprior(x)=∥x−φθ(x)∥2.J_\text{prior}(x) = \|x - \varphi_\theta(x)\|^2.Jprior​(x)=∥x−φθ​(x)∥2.
(3)

The two forms cannot be mixed — pass one set of arguments or the other.

model_error_cost(eta, Q_inv_op)¶

Weak-constraint 4DVar model-error term:

Jη(η)=12∑t=1T∥ηt∥Qt−12.J_\eta(\boldsymbol{\eta}) = \tfrac{1}{2} \sum_{t=1}^{T} \|\eta_t\|^2_{Q_t^{-1}}.Jη​(η)=21​t=1∑T​∥ηt​∥Qt−1​2​.
(4)

variational_cost(x, batch, prior_fn, obs_operator, alpha_obs=1.0, alpha_prior=1.0)¶

Weak-constraint variational cost (learned-prior form):

J(x)=αobsJobs(x)+αpriorJprior(x).J(x) = \alpha_\text{obs} J_\text{obs}(x) + \alpha_\text{prior} J_\text{prior}(x).J(x)=αobs​Jobs​(x)+αprior​Jprior​(x).
(5)

Used by FourDVarNet.

threedvar_cost(x, batch, obs_operator, prior_mean, B_inv_op, R_inv_op)¶

Classical 3DVar cost:

J(x)=12∥x−xb∥B−12+12∥y−H(x)∥R−12.J(x) = \tfrac{1}{2} \|x - x_b\|^2_{B^{-1}} + \tfrac{1}{2} \|y - H(x)\|^2_{R^{-1}}.J(x)=21​∥x−xb​∥B−12​+21​∥y−H(x)∥R−12​.
(6)

incremental_cost(δx, x_b, batch, forward_lin, obs_op_lin, B_inv_op, R_inv_op)¶

Linearised incremental cost for the 4DVar inner loop:

Jinc(δx)=12∥δx∥B−12+12∑t∥yt−Ht(xb)−Ht′Mt′δx∥R−12.J_\text{inc}(\delta x) = \tfrac{1}{2} \|\delta x\|^2_{B^{-1}} + \tfrac{1}{2} \sum_t \|y_t - H_t(x_b) - H'_t M'_t \delta x\|^2_{R^{-1}}.Jinc​(δx)=21​∥δx∥B−12​+21​t∑​∥yt​−Ht​(xb​)−Ht′​Mt′​δx∥R−12​.
(7)

Ht′H'_tHt′​ and Mt′M'_tMt′​ are tangent-linear operators at the outer iterate xbx_bxb​.

Closed-form analysis¶

blue_analysis(x_b, y, B_op, R_op, H_op)¶

BLUE / OI in closed form (Decision D16):

x∗=xb+BH⊤(HBH⊤+R)−1(y−Hxb).x^* = x_b + B H^\top (H B H^\top + R)^{-1} (y - H x_b).x∗=xb​+BH⊤(HBH⊤+R)−1(y−Hxb​).
(8)

Returns (x_star, posterior_cov_op) where posterior_cov_op is an AbstractLinearOperator representing P∗P^*P∗ — not materialised by default. gaussx exploits structure in BBB, RRR, HHH.

The implementation picks between the BBB-space form (Sherman-Morrison- Woodbury, useful when state is high-dimensional) and the RRR-space form (useful when observation count is low) based on dimensions.

Control-variable transform¶

cvt_transform(x, x_b, B_half_op) and cvt_inverse(chi, x_b, B_half_op)¶

CVT: χ=B−1/2(x−xb)\chi = B^{-1/2}(x - x_b)χ=B−1/2(x−xb​), with inverse x=xb+B1/2χx = x_b + B^{1/2}\chix=xb​+B1/2χ.

B1/2B^{1/2}B1/2 comes from gaussx.MaternLinearOperator.half() when the prior is Matérn; falls back to Cholesky factorisation for arbitrary AbstractLinearOperator.

In CVT coordinates the prior cost is ∥χ∥2\|\chi\|^2∥χ∥2 (identity Gaussian), which preconditions the CG inner loop in IncrementalFourDVar.

Posterior primitives¶

laplace_covariance(x_star, cost_grad_fn, B_inv_op, R_inv_op)¶

Laplace approximation at MAP:

P∗=((H′)⊤R−1H′+B−1)−1.P^* = \big((H')^\top R^{-1} H' + B^{-1}\big)^{-1}.P∗=((H′)⊤R−1H′+B−1)−1.
(9)

Returns AbstractLinearOperator — supports mat-vec via lineax.CG, no materialisation.

gauss_newton_hessian(x_star, batch, forward, obs_op, B_op, R_op, n_krylov=50)¶

Gauss-Newton Hessian at MAP, via Krylov / Lanczos. Returns AbstractLinearOperator representing J′′(x∗)J''(x^*)J′′(x∗) for posterior inversion.

L(θ)=∥x∗(θ)−xtrue∥2.\mathcal{L}(\theta) = \|x^*(\theta) - x_\text{true}\|^2.L(θ)=∥x∗(θ)−xtrue​∥2.

train_loss_fn(model, batch)¶

Forward through model(batch) → x*, then reconstruction_loss(x*, batch.target). Gradients flow through the inner solver according to model.solver_adjoint.

train_step(model, batch, optimizer, opt_state)¶

One outer training step: loss → backprop → optimiser update. Encodes the correctness-critical differentiation pattern (Decisions D5, D15).

Removed in v0.4¶

The following Layer 0 primitives from v0.3 are removed:

  • solver_step(x, grad_J, grad_mod_fn, carry) — moved into FourDVarNet internals

  • unrolled_solve(x0, cost_fn, grad_mod_fn, n_steps, carry0) — replaced by optimistix.RecursiveCheckpointAdjoint

  • one_step_solve(...) — replaced by vardax.adjoints.OneStepAdjoint (targeting upstream)

  • implicit_solve(...) — replaced by optimistix.ImplicitAdjoint

  • GradMode literal type — removed from public API

If you need the gradient-strategy behaviour, configure model.solver_adjoint (for FourDVarNet) or model.minimiser_adjoint (for classical methods).
