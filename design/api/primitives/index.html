Layer 0 — Primitives

Pure JAX functions. Stateless, differentiable, no eqx.Module, no optimistix. The mathematical building blocks that Layer 1 operators compose.

v0.4 removes the in-house gradient-mode primitives (unrolled_solve, one_step_solve, implicit_solve) in favour of upstream optimistix.AbstractAdjoint and diffrax.AbstractAdjoint (Decision D15). The remaining primitives are mathematical, not differentiation strategies.

Cost terms¶

obs_cost(x, y_obs, mask, obs_operator=None, R_inv_op=None)¶

Observation cost:

Jo(x)=12∥h(x)−y∥Σε−12.\mathcal{J}_o(\vect{x}) = \frac{1}{2} \Vert h(\vect{x}) - \vect{y} \Vert^2_{\gmat{\Sigma}_\varepsilon^{-1}}.Jo​(x)=21​∥h(x)−y∥Σε−1​2​.
(1)

When obs_operator=None, hhh defaults to masked identity. When R_inv_op=None, Σε−1\gmat{\Sigma}_\varepsilon^{-1}Σε−1​ defaults to I/∣Ω∣\mat{I} / \vert \Omega \vertI/∣Ω∣ (averaged MSE).

prior_cost(x, prior_mean=None, B_inv_op=None, prior_fn=None)¶

Two distinct meanings depending on which kwargs are passed:

Classical (prior_mean and B_inv_op supplied):

Jp(x)=12∥x−μx∥Σx−12.\mathcal{J}_p(\vect{x}) = \frac{1}{2} \Vert \vect{x} - \gvect{\mu}_x \Vert^2_{\gmat{\Sigma}_x^{-1}}.Jp​(x)=21​∥x−μx​∥Σx−1​2​.
(2)

Learned (prior_fn supplied — FourDVarNet):

Jp(x)=∥x−gae(x;θ)∥2.\mathcal{J}_p(\vect{x}) = \Vert \vect{x} - g_\text{ae}(\vect{x}; \gvect{\theta}) \Vert^2.Jp​(x)=∥x−gae​(x;θ)∥2.
(3)

The two forms cannot be mixed — pass one set of arguments or the other.

model_error_cost(eta, Q_inv_op)¶

Weak-constraint 4DVar model-error term:

Jη(η)=12∑t=1T∥ηt∥Ση,t−12.\mathcal{J}_\eta(\gvect{\eta}) = \frac{1}{2} \sum_{t=1}^{T} \Vert \gvect{\eta}_t \Vert^2_{\gmat{\Sigma}_{\eta,t}^{-1}}.Jη​(η)=21​t=1∑T​∥ηt​∥Ση,t−1​2​.
(4)

variational_cost(x, batch, prior_fn, obs_operator, alpha_obs=1.0, alpha_prior=1.0)¶

Weak-constraint variational cost (learned-prior form):

J(x)=αobsJo(x)+αpriorJp(x).\mathcal{J}(\vect{x}) = \alpha_\text{obs} \mathcal{J}_o(\vect{x}) + \alpha_\text{prior} \mathcal{J}_p(\vect{x}).J(x)=αobs​Jo​(x)+αprior​Jp​(x).
(5)

Used by FourDVarNet.

threedvar_cost(x, batch, obs_operator, prior_mean, B_inv_op, R_inv_op)¶

Classical 3DVar cost:

J(x)=12∥x−μx∥Σx−12+12∥y−h(x)∥Σε−12.\mathcal{J}(\vect{x}) = \frac{1}{2} \Vert \vect{x} - \gvect{\mu}_x \Vert^2_{\gmat{\Sigma}_x^{-1}} + \frac{1}{2} \Vert \vect{y} - h(\vect{x}) \Vert^2_{\gmat{\Sigma}_\varepsilon^{-1}}.J(x)=21​∥x−μx​∥Σx−1​2​+21​∥y−h(x)∥Σε−1​2​.
(6)

incremental_cost(δx, x_b, batch, forward_lin, obs_op_lin, B_inv_op, R_inv_op)¶

Linearised incremental cost for the 4DVar inner loop:

δJ(δx)=12∥δx∥Σx−12+12∑t∥yt−ht(μx)−HtFtδx∥Σε−12.\delta\mathcal{J}(\delta\vect{x}) = \frac{1}{2} \Vert \delta\vect{x} \Vert^2_{\gmat{\Sigma}_x^{-1}} + \frac{1}{2} \sum_t \Vert \vect{y}_t - h_t(\gvect{\mu}_x) - \mat{H}_t \mat{F}_t \delta\vect{x} \Vert^2_{\gmat{\Sigma}_\varepsilon^{-1}}.δJ(δx)=21​∥δx∥Σx−1​2​+21​t∑​∥yt​−ht​(μx​)−Ht​Ft​δx∥Σε−1​2​.
(7)

Ht\mat{H}_tHt​ and Ft\mat{F}_tFt​ are tangent-linear operators at the outer iterate μx\gvect{\mu}_xμx​.

Closed-form analysis¶

blue_analysis(x_b, y, B_op, R_op, H_op)¶

BLUE / OI in closed form (Decision D16):

x⋆=μx+ΣxH⊤(HΣxH⊤+Σε)−1(y−Hμx).\vect{x}^\star = \gvect{\mu}_x + \gmat{\Sigma}_x \mat{H}^\top (\mat{H} \gmat{\Sigma}_x \mat{H}^\top + \gmat{\Sigma}_\varepsilon)^{-1} (\vect{y} - \mat{H} \gvect{\mu}_x).x⋆=μx​+Σx​H⊤(HΣx​H⊤+Σε​)−1(y−Hμx​).
(8)

Returns (x_star, posterior_cov_op) where posterior_cov_op is an AbstractLinearOperator representing Σx∣y\gmat{\Sigma}_{x \mid y}Σx∣y​ — not materialised by default. gaussx exploits structure in Σx\gmat{\Sigma}_xΣx​, Σε\gmat{\Sigma}_\varepsilonΣε​, H\mat{H}H.

The implementation picks between the Σx\gmat{\Sigma}_xΣx​-space form (Sherman-Morrison- Woodbury, useful when state is high-dimensional) and the Σε\gmat{\Sigma}_\varepsilonΣε​-space form (useful when observation count is low) based on dimensions.

Control-variable transform¶

cvt_transform(x, x_b, B_half_op) and cvt_inverse(chi, x_b, B_half_op)¶

CVT: z=Lx−1(x−μx)\vect{z} = \mat{L}_x^{-1} (\vect{x} - \gvect{\mu}_x)z=Lx−1​(x−μx​), with inverse x=μx+Lxz\vect{x} = \gvect{\mu}_x + \mat{L}_x \vect{z}x=μx​+Lx​z, where Lx=Σx1/2\mat{L}_x = \gmat{\Sigma}_x^{1/2}Lx​=Σx1/2​.

Lx\mat{L}_xLx​ comes from gaussx.MaternLinearOperator.half() when the prior is Matérn; falls back to Cholesky factorisation for arbitrary AbstractLinearOperator.

In CVT coordinates the prior cost is ∥z∥2\Vert \vect{z} \Vert^2∥z∥2 (identity Gaussian), which preconditions the CG inner loop in IncrementalFourDVar.

Posterior primitives¶

laplace_covariance(x_star, cost_grad_fn, B_inv_op, R_inv_op)¶

Laplace approximation at MAP:

Σx∣y=(H⊤Σε−1H+Σx−1)−1.\gmat{\Sigma}_{x \mid y} = \left(\mat{H}^\top \gmat{\Sigma}_\varepsilon^{-1} \mat{H} + \gmat{\Sigma}_x^{-1}\right)^{-1}.Σx∣y​=(H⊤Σε−1​H+Σx−1​)−1.

train_loss_fn(model, batch)¶

Forward through model(batch) → x*, then reconstruction_loss(x*, batch.target). Gradients flow through the inner solver according to model.solver_adjoint.

train_step(model, batch, optimizer, opt_state)¶

One outer training step: loss → backprop → optimiser update. Encodes the correctness-critical differentiation pattern (Decisions D5, D15).

Removed in v0.4¶

The following Layer 0 primitives from v0.3 are removed:

  • solver_step(x, grad_J, grad_mod_fn, carry) — moved into FourDVarNet internals

  • unrolled_solve(x0, cost_fn, grad_mod_fn, n_steps, carry0) — replaced by optimistix.RecursiveCheckpointAdjoint

  • one_step_solve(...) — replaced by vardax.adjoints.OneStepAdjoint (targeting upstream)

  • implicit_solve(...) — replaced by optimistix.ImplicitAdjoint

  • GradMode literal type — removed from public API

If you need the gradient-strategy behaviour, configure model.solver_adjoint (for FourDVarNet) or model.minimiser_adjoint (for classical methods).
