  1. Layer 0 — Primitive Examples — Layer 0: cost terms, closed-form BLUE, CVT, adjoint composition via optimistix / diffrax.

  2. Layer 1 — Component Examples — Layer 1: implementing Prior, ObservationOperator, GradModulator, PosteriorAdapter, Minimiser.

  5. End-to-end Use Cases — full walkthroughs anchoring the abstractions on real workflows.
