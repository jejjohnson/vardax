    Training & Adjoints¶

    Training a learned solver means differentiating through an inner optimisation loop, and how you do that determines memory cost and gradient quality. The adjoint strategies here make that choice explicit and swappable — see Adjoint Methods in the Mathematical Reference for the trade-offs. Around them sit the loss functions and train/eval steps for 4DVarNet and the amortized posteriors, and the ConvLSTM gradient modulators that 4DVarNet learns in place of a hand-tuned inner optimiser.

    Adjoint strategies¶

    Implementations of vardax.adjoints (Decision D15): full backpropagation with checkpointed memory (RecursiveCheckpointAdjoint), truncated one-step gradients (OneStepAdjoint, pairing with the one_step_solve_* solver functions), and implicit differentiation at a fixed point (ImplicitAdjoint, pairing with solve_4dvarnet_1d_fixedpoint). All three are also accessible via the vardax.adjoints submodule namespace. Use assert_adjoint_calibrated to verify a cheap adjoint against the exact one before trusting it.

    RecursiveCheckpointAdjoint and ImplicitAdjoint are re-exported from optimistix for one-stop import; see the optimistix documentation for their full signatures:

    • vardax.RecursiveCheckpointAdjoint — optimistix.RecursiveCheckpointAdjoint, exact reverse-mode backpropagation through the unrolled inner loop with binomial checkpointing (the default).
    • vardax.ImplicitAdjoint — optimistix.ImplicitAdjoint, implicit-function-theorem differentiation at a fixed point; pair with solve_4dvarnet_1d_fixedpoint.

    KStepAdjoint(k) is vardax's own truncated adjoint — warmup under stop_gradient, then k differentiable steps; OneStepAdjoint is the k=1 alias (Bolte, Pauwels & Vaiter, NeurIPS 2023):

    vardax — Modular variational data assimilation with learned components.

    All public symbols are re-exported from the private _src subpackage so that user code imports from the top-level namespace:

    import vardax

model = vardax.FourDVarNet1D(...)

    K-step differentiation: warmup under stop_gradient, then k live steps.

    For a solver iteration \(z_{j+1} = T(z_j)\) run \(n\) times, the gradient flows only through the last \(k\) steps,

    \[ \frac{d z_n}{d\phi} \approx \frac{\partial T^{k}(\bar z_{n-k})}{\partial\phi} \]

    where \(\bar z_{n-k}\) is the iterate after the warmup, held fixed.

    Algorithm
    1. Run the first \(n - k\) solver iterations under jax.lax.stop_gradient.
    2. Run the last \(k\) iterations differentiably.
    3. Backpropagate through those \(k\) iterations only, at memory cost \(O(k)\).

    key=key,

    r"""K-step differentiation: warmup under ``stop_gradient``, then ``k`` live steps.

    For a solver iteration $z_{j+1} = T(z_j)$ run $n$ times, the gradient
    flows only through the last $k$ steps,

    $$ \frac{d z_n}{d\phi} \approx \frac{\partial T^{k}(\bar z_{n-k})}{\partial\phi} $$

    where $\bar z_{n-k}$ is the iterate after the warmup, held fixed.

    Algorithm:
        1. Run the first $n - k$ solver iterations under
           ``jax.lax.stop_gradient``.
        2. Run the last $k$ iterations differentiably.
        3. Backpropagate through those $k$ iterations only, at memory cost
           $O(k)$.

    Use as the ``solver_adjoint`` argument to
    [`FourDVarNet1D`][vardax.FourDVarNet1D] /
    [`FourDVarNet2D`][vardax.FourDVarNet2D]:

    ```python
    from vardax.adjoints import KStepAdjoint

    model = FourDVarNet1D(
        state_dim=N, n_time=T, ...,
        solver_adjoint=KStepAdjoint(k=3),
        key=key,
    )
    ```

    Raises:
        ConfigurationError: If ``k`` is below 1.

    Attributes:
        k: Number of trailing solver iterations that propagate
            gradients. Must be at least 1; values larger than
            ``n_solver_steps`` are clipped to a fully differentiable
            solve.

        >>> import vardax
        >>> vardax.KStepAdjoint(k=3)
        KStepAdjoint(k=3)

        ``k=1`` is the one-step estimator, and `OneStepAdjoint` is a
        subclass.

        >>> isinstance(vardax.OneStepAdjoint(), vardax.KStepAdjoint)
        True
        >>> vardax.KStepAdjoint().k
        1

        A non-positive ``k`` is rejected.

        >>> vardax.KStepAdjoint(k=0)  # doctest: +IGNORE_EXCEPTION_DETAIL
        Traceback (most recent call last):
        ...
        ConfigurationError: KStepAdjoint needs k >= 1; got k=0.

    References:
        Bolte, J., Pauwels, E. & Vaiter, S. (2023). One-step

        [arXiv:2305.13768](https://arxiv.org/abs/2305.13768).

    OneStepAdjoint ¶

    Bases: KStepAdjoint

    One-step differentiation (Bolte et al., 2023).

    Run K - 1 warmup iterations of the inner solver with jax.lax.stop_gradient, then one differentiable step. Gives O(1) memory and is exact at the fixed point of the inner iteration.

    \[ \frac{d z^\star}{d\phi} \approx \partial_\phi T(\bar z_{K-1}; \phi) \]

    where \(\bar z_{K-1}\) is the iterate after the warmup, held fixed.

    Algorithm
    1. Run \(K - 1\) solver iterations under jax.lax.stop_gradient.
    2. Run the last iteration differentiably.
    3. Backpropagate through that single step.

    Use as the solver_adjoint argument to FourDVarNet1D / FourDVarNet2D:

    from vardax.adjoints import OneStepAdjoint

model = FourDVarNet1D(
    state_dim=N, n_time=T, ...,
    solver_adjoint=OneStepAdjoint(),
    key=key,
)

    Examples:

    >>> import vardax
>>> adjoint = vardax.OneStepAdjoint()
>>> adjoint
OneStepAdjoint()
>>> adjoint.k
1

    It is KStepAdjoint with k=1.

    >>> isinstance(adjoint, vardax.KStepAdjoint)
True
    References

    Bolte, J., Pauwels, E. & Vaiter, S. (2023). One-step differentiation of iterative algorithms. NeurIPS 36. arXiv:2305.13768.

    def to_optimistix_adjoint(spec: Any) -> optx.AbstractAdjoint:
    """Map an adjoint spec onto an ``optimistix.AbstractAdjoint``.

    Algorithm:
        1. Return ``spec`` unchanged if it already is an
           ``optimistix.AbstractAdjoint``.
        2. Otherwise match it by class name against the mapping below.
        3. Raise for names that have no inner-solve counterpart.

    Mapping:

    - ``ImplicitAdjoint()`` → ``optx.ImplicitAdjoint()`` — exact at a
      converged fixed point, O(1) memory, one Hessian linear solve.
    - ``RecursiveCheckpointAdjoint(checkpoints)`` →
      ``optx.RecursiveCheckpointAdjoint(checkpoints)`` — exact,
      recomputing.
    - ``TruncatedAdjoint(k)`` →
      [`KStepAdjoint(k)`][vardax.adjoints.KStepAdjoint] — warmup under
      ``stop_gradient``, then ``k`` differentiable steps (``k=1`` is
      [`OneStepAdjoint`][vardax.adjoints.OneStepAdjoint]).
    - ``DirectAdjoint`` / ``BacksolveAdjoint`` →
      [`UnsupportedInputError`][vardax.UnsupportedInputError]: the
      first is the plain unrolled default (pass
      ``optx.RecursiveCheckpointAdjoint()`` or nothing), the second
      only exists at the dynamics layer.

    Args:
        spec: A spec from ``pipekit_cycle.adjoints`` or any
            structurally identical object. A ready-made
            ``optx.AbstractAdjoint`` passes through unchanged.

    Returns:
        The corresponding optimistix adjoint instance.

    Raises:
        UnsupportedInputError: For layer-inappropriate or unrecognised specs.

    Examples:
        >>> import optimistix as optx
        >>> from pipekit_cycle.adjoints import TruncatedAdjoint
        >>> from vardax.adjoints import to_optimistix_adjoint
        >>> to_optimistix_adjoint(TruncatedAdjoint(k=3))
        KStepAdjoint(k=3)
        >>> isinstance(
        ...     to_optimistix_adjoint(optx.ImplicitAdjoint()), optx.ImplicitAdjoint
        ... )
        True

        A pipekit ``TruncatedAdjoint(k=1)`` is the one-step adjoint.

        >>> import vardax
        >>> adjoint = to_optimistix_adjoint(TruncatedAdjoint(k=1))
        >>> isinstance(adjoint, vardax.OneStepAdjoint)
        False
        >>> isinstance(adjoint, vardax.KStepAdjoint)
        True

        A spec with no inner-solve meaning is rejected.

        >>> from pipekit_cycle.adjoints import DirectAdjoint
        >>> to_optimistix_adjoint(DirectAdjoint())  # doctest: +IGNORE_EXCEPTION_DETAIL
        Traceback (most recent call last):
        ...
        UnsupportedInputError: DirectAdjoint does not apply at the inner-solve layer
    """
    if isinstance(spec, optx.AbstractAdjoint):
        return spec
    name = type(spec).__name__
    if name == "ImplicitAdjoint":
        return optx.ImplicitAdjoint()
    if name == "RecursiveCheckpointAdjoint":
        return optx.RecursiveCheckpointAdjoint(
            checkpoints=getattr(spec, "checkpoints", None)
        )
    if name == "TruncatedAdjoint":
        return KStepAdjoint(k=getattr(spec, "k", 1))
    if name in ("DirectAdjoint", "BacksolveAdjoint"):
        raise UnsupportedInputError(
            f"{name} does not apply at the inner-solve layer: DirectAdjoint is "
            "the plain unrolled default (use optx.RecursiveCheckpointAdjoint() "
            "or omit solver_adjoint), and BacksolveAdjoint only exists at the "
            "dynamics layer (see pipekit_jax.DiffraxForwardModel)."
        )
    raise UnsupportedInputError(f"Unrecognised adjoint spec: {spec!r}")

    Gradient modulators¶

    The learned components of 4DVarNet: ConvLSTM cells that map the raw variational-cost gradient to a descent update, satisfying the GradModulator Protocol. Their recurrent state is carried in the LSTMState1D / LSTMState2D containers.

    vardax — Modular variational data assimilation with learned components.

    All public symbols are re-exported from the private _src subpackage so that user code imports from the top-level namespace:

    import vardax

model = vardax.FourDVarNet1D(...)

    ConvLSTMGradMod1D ¶

    Bases: Module

    1-D ConvLSTM-based gradient modulator.

    Accepts the concatenation of the current state and its gradient as input and produces a modulated gradient update (and updated LSTM state). With \(g = \nabla J(u)\) and previous memory \((h, c)\) the gates are

    \[ [i; f; \tilde c; o] = W_x [g; u] + W_h h, \quad c' = \sigma(f) \odot c + \sigma(i) \odot \tanh(\tilde c), \quad h' = \sigma(o) \odot \tanh(c'), \]

    and the update is \(W_o h'\).

    Algorithm
    1. Stack the gradient over the state along the channel axis and apply the input convolution; add the convolution of the hidden state.
    2. Split into the input, forget, candidate and output gates.
    3. Update the cell state \(c'\) and the hidden state \(h'\).
    4. Map \(h'\) back to the state channels with the output convolution.

    Parameters:

    Name Type Description Default
    state_channels int

    Number of channels in the state / gradient (T).

    		 required
    hidden_dim int

    Number of hidden channels in the LSTM.

    		 required
    kernel_size int

    1-D convolution kernel size.

    		 3
    key PRNGKeyArray

    PRNG key for the convolution weights.

    		 required

    Examples:

    The update has the shape of the gradient, the memory the shape of the hidden state:

    >>> import jax
>>> import jax.numpy as jnp
>>> import vardax as vdx
>>> mod = vdx.ConvLSTMGradMod1D(
...     state_channels=3, hidden_dim=5, key=jax.random.PRNGKey(0)
... )
>>> grad = jnp.ones((2, 3, 4))
>>> update, lstm = mod(grad, grad, vdx.LSTMState1D.zeros(2, 5, 4))
>>> update.shape, lstm.hidden.shape
((2, 3, 4), (2, 5, 4))

    The memory is carried across solver steps, so a second call with the returned state gives a different update:

    >>> update2, _ = mod(grad, grad, lstm)
>>> bool(jnp.allclose(update, update2))
False

    class ConvLSTMGradMod1D(eqx.Module):
    r"""1-D ConvLSTM-based gradient modulator.

    Accepts the concatenation of the current state and its gradient as input
    and produces a modulated gradient update (and updated LSTM state).  With
    $g = \nabla J(u)$ and previous memory $(h, c)$ the gates are

    $$
    [i; f; \tilde c; o] = W_x [g; u] + W_h h, \quad
    c' = \sigma(f) \odot c + \sigma(i) \odot \tanh(\tilde c), \quad
    h' = \sigma(o) \odot \tanh(c'),
    $$

    and the update is $W_o h'$.

    Algorithm:
        1. Stack the gradient over the state along the channel axis and apply
           the input convolution; add the convolution of the hidden state.
        2. Split into the input, forget, candidate and output gates.
        3. Update the cell state $c'$ and the hidden state $h'$.
        4. Map $h'$ back to the state channels with the output convolution.

    Args:
        state_channels: Number of channels in the state / gradient (``T``).
        hidden_dim: Number of hidden channels in the LSTM.
        kernel_size: 1-D convolution kernel size.
        key: PRNG key for the convolution weights.

    Examples:
        The update has the shape of the gradient, the memory the shape of the
        hidden state:

        >>> import jax
        >>> import jax.numpy as jnp
        >>> import vardax as vdx
        >>> mod = vdx.ConvLSTMGradMod1D(
        ...     state_channels=3, hidden_dim=5, key=jax.random.PRNGKey(0)
        ... )
        >>> grad = jnp.ones((2, 3, 4))
        >>> update, lstm = mod(grad, grad, vdx.LSTMState1D.zeros(2, 5, 4))
        >>> update.shape, lstm.hidden.shape
        ((2, 3, 4), (2, 5, 4))

        The memory is carried across solver steps, so a second call with the
        returned state gives a different update:

        >>> update2, _ = mod(grad, grad, lstm)
        >>> bool(jnp.allclose(update, update2))
        False
    """

    state_channels: int = eqx.field(static=True)
    hidden_dim: int = eqx.field(static=True)
    kernel_size: int = eqx.field(static=True)
    _gates_input_conv: eqx.nn.Conv1d
    _gates_hidden_conv: eqx.nn.Conv1d
    _output_conv: eqx.nn.Conv1d

    def __init__(
        self,
        state_channels: int,
        hidden_dim: int,
        kernel_size: int = 3,
        *,
        key: PRNGKeyArray,
    ) -> None:
        self.state_channels = state_channels
        self.hidden_dim = hidden_dim
        self.kernel_size = kernel_size
        key_input, key_hidden, key_output = jax.random.split(key, 3)
        pad = kernel_size // 2
        self._gates_input_conv = eqx.nn.Conv1d(
            in_channels=2 * state_channels,
            out_channels=4 * hidden_dim,
            kernel_size=kernel_size,
            padding=pad,
            key=key_input,
        )
        self._gates_hidden_conv = eqx.nn.Conv1d(
            in_channels=hidden_dim,
            out_channels=4 * hidden_dim,
            kernel_size=kernel_size,
            padding=pad,
            key=key_hidden,
        )
        self._output_conv = eqx.nn.Conv1d(
            in_channels=hidden_dim,
            out_channels=state_channels,
            kernel_size=kernel_size,
            padding=pad,
            key=key_output,
        )

    def __call__(
        self,
        grad: Float[Array, "B T N"],
        state: Float[Array, "B T N"],
        lstm_state: LSTMState1D,
    ) -> tuple[Float[Array, "B T N"], LSTMState1D]:
        """Forward pass.

        Args:
            grad: Gradient of the variational cost with respect to the state.
            state: Current state estimate.
            lstm_state: Current LSTM hidden/cell state with ``hidden_dim`` channels.

        Returns:
            The modulated gradient update and the new LSTM state.
        """
        # eqx.nn.Conv1d operates on (channels, spatial). Our arrays are already
        # (B, channels, spatial) with T=channels for grad/state and H=channels
        # for the LSTM state — vmap over the leading batch dim.

        def _forward(
            grad_sample: Float[Array, "T N"],
            state_sample: Float[Array, "T N"],
            hidden_sample: Float[Array, "H N"],
            cell_sample: Float[Array, "H N"],
        ) -> tuple[Float[Array, "T N"], Float[Array, "H N"], Float[Array, "H N"]]:
            # the input channels are the gradient stacked over the state
            stacked_input = einx.id("a n, b n -> (a + b) n", grad_sample, state_sample)
            # gates = W_x [∇J; u] + W_h h
            gates = self._gates_input_conv(stacked_input) + self._gates_hidden_conv(
                hidden_sample
            )
            # [i; f; g; o] = split(gates)
            input_gate, forget_gate, cell_candidate, output_gate = einx.id(
                "(gate h) n -> gate h n", gates, gate=4
            )
            input_gate = jax.nn.sigmoid(input_gate)
            forget_gate = jax.nn.sigmoid(forget_gate)
            cell_candidate = jnp.tanh(cell_candidate)
            output_gate = jax.nn.sigmoid(output_gate)
            # c' = f ⊙ c + i ⊙ g
            new_cell = forget_gate * cell_sample + input_gate * cell_candidate
            # h' = o ⊙ tanh(c')
            new_hidden = output_gate * jnp.tanh(new_cell)
            update = self._output_conv(new_hidden)
            return update, new_hidden, new_cell

        update, new_hidden, new_cell = jax.vmap(_forward)(
            grad, state, lstm_state.hidden, lstm_state.cell
        )
        return update, LSTMState1D(hidden=new_hidden, cell=new_cell)

def train_step(
    model: Any,
    batch: Batch1D | Batch2D,
    optimizer: optax.GradientTransformation,
    opt_state: optax.OptState,
) -> tuple[Any, optax.OptState, Float[Array, ""]]:
    """Perform a single training step (forward + backward + update).

    This is the correctness-critical primitive: gradients flow through
    the FourDVarNet inner solver according to whichever differentiation
    strategy (the model's ``solver_adjoint``) the model is configured with.
    Users should compose this primitive into their training loop
    (notebook-level or ``pipekit_train.TrainingLoop``) rather than
    reimplementing it.

    Algorithm:
        1. Evaluate [`train_loss_fn`][vardax.train_loss_fn] and its gradient with
           respect to the model parameters.
        2. Turn the gradient into an update with the optax optimiser.
        3. Apply the update to the model.

    Args:
        model: Equinox module to optimise.
        batch: Training batch.
        optimizer: Optax gradient transformation (e.g. ``optax.adam(1e-3)``).
        opt_state: Current optimiser state.

    Returns:
        The updated model, the updated optimiser state and the scalar loss
        (evaluated before the update).

    Raises:
        MissingInputError: If ``batch.target`` is ``None``.

    Examples:
        >>> import jax
        >>> import jax.numpy as jnp
        >>> import equinox as eqx
        >>> import optax
        >>> import vardax as vdx
        >>> model = vdx.FourDVarNet1D(
        ...     state_dim=4,
        ...     n_time=3,
        ...     latent_dim=2,
        ...     hidden_dim=3,
        ...     n_solver_steps=1,
        ...     key=jax.random.PRNGKey(0),
        ... )
        >>> ones = jnp.ones((2, 3, 4))
        >>> batch = vdx.Batch1D(input=ones, mask=ones, target=jnp.zeros((2, 3, 4)))
        >>> optimizer = optax.adam(1e-2)
        >>> opt_state = optimizer.init(eqx.filter(model, eqx.is_array))
        >>> new_model, opt_state, loss = vdx.train_step(
        ...     model, batch, optimizer, opt_state
        ... )
        >>> loss.shape
        ()

        The step returns the pre-update loss, so it equals ``eval_step`` on the
        old model, and the parameters have moved:

        >>> bool(jnp.allclose(loss, vdx.eval_step(model, batch)))
        True
        >>> bool(eqx.tree_equal(new_model, model))
        False
    """
    loss, grads = eqx.filter_value_and_grad(train_loss_fn)(model, batch)
    updates, opt_state = optimizer.update(grads, opt_state, model)
    model = eqx.apply_updates(model, updates)
    return model, opt_state, loss
