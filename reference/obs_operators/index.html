    Observation Operators¶

    Observation operators map model state to observation space. All of them satisfy the pipekit-cycle ObservationOperator Protocol — __call__(state) produces the predicted observation, and linearize(state) returns the tangent-linear (Jacobian) operator that the incremental and posterior-covariance machinery needs. Because conformance is structural, custom operators plug in by matching that signature; nothing here needs to be subclassed. See Observation Operators in the Mathematical Reference for the modelling background.

    Core operators¶

    LinearObs wraps an explicit observation matrix; CallableObs turns any differentiable JAX function (a model run, a simulator, an emulator) into an operator, with its tangent-linear map from autodiff; MaskedIdentity handles the ubiquitous "observe a subset of grid points" case (satellite tracks, sparse sensor networks); AveragingKernel implements the smoothing kernels of retrieval products such as atmospheric-composition column averages.

    vardax — Modular variational data assimilation with learned components.

    All public symbols are re-exported from the private _src subpackage so that user code imports from the top-level namespace:

    import vardax

model = vardax.FourDVarNet1D(...)

    CallableObs ¶

    Bases: Module

    \(H(x) = f(x)\) for any differentiable JAX function \(f\).

    linearize(x) is a matrix-free lineax.JacobianLinearOperator at x: its mv is a JVP of \(f\) and its transpose().mv a VJP, so nothing of size \(\dim y \times \dim x\) is ever formed. The operator is an Equinox module, so it works under eqx.filter_jit and jax.vmap; when fn is itself an Equinox module (an eqx.nn.MLP emulator, say), its parameters are pytree leaves and eqx.filter_grad differentiates through them.

    Prefer LinearObs when you already hold an explicit or structured matrix you want to reuse; use this for a model run, a simulator or an emulator.

    Pass jac="bwd" for a model that defines only a reverse-mode rule (a jax.custom_vjp function): forward mode raises on it as soon as an analysis or posterior linearises the operator. Matrix-free, lineax then applies \(H'v\) by transposing the VJP, which fails when the backward pass contains a loop JAX cannot transpose, as a diffrax solve's does (RecursiveCheckpointAdjoint runs a while_loop). For those, also pass materialise=True: linearize then forms the Jacobian once, with one VJP per observation (jax.jacrev), and both \(H'\) and \(H'^\top\) are dense products. That suits a small control, the usual case for source and parameter estimation.

True

    class CallableObs(eqx.Module):
    r"""$H(x) = f(x)$ for any differentiable JAX function $f$.

    ``linearize(x)`` is a matrix-free ``lineax.JacobianLinearOperator`` at
    ``x``: its ``mv`` is a JVP of $f$ and its ``transpose().mv`` a VJP, so
    nothing of size $\dim y \times \dim x$ is ever formed. The operator is
    an Equinox module, so it works under ``eqx.filter_jit`` and
    ``jax.vmap``; when ``fn`` is itself an Equinox module (an
    ``eqx.nn.MLP`` emulator, say), its parameters are pytree leaves and
    ``eqx.filter_grad`` differentiates through them.

    Prefer [`LinearObs`][vardax.LinearObs] when you already hold an explicit
    or structured matrix you want to reuse; use this for a model run, a
    simulator or an emulator.

    Pass ``jac="bwd"`` for a model that defines only a reverse-mode rule
    (a ``jax.custom_vjp`` function): forward mode raises on it as soon as
    an analysis or posterior linearises the operator. Matrix-free, lineax
    then applies $H'v$ by transposing the VJP, which fails when the
    backward pass contains a loop JAX cannot transpose, as a ``diffrax``
    solve's does (``RecursiveCheckpointAdjoint`` runs a ``while_loop``).
    For those, also pass ``materialise=True``: ``linearize`` then forms the
    Jacobian once, with one VJP per observation (``jax.jacrev``), and both
    $H'$ and $H'^\top$ are dense products. That suits a small control, the
    usual case for source and parameter estimation.

    Attributes:
        fn: The observation map $f$, from a state of any shape to an
            observation of any shape.
        jac: How ``linearize`` differentiates ``fn``: ``None`` (lineax's
            default, forward mode), ``"fwd"`` or ``"bwd"`` (reverse mode).
        materialise: Form the Jacobian in ``linearize`` instead of keeping
            it matrix-free, with ``jax.jacrev`` for ``jac="bwd"`` and
            ``jax.jacfwd`` otherwise. Default ``False``.

    Examples:
        A linear $f(x) = F x$ on a ``(1, N)`` state with $M \ne N$
        observations: ``OptimalInterpolation`` with $B = R = I$ gives the
        closed-form BLUE, $x^* = (I + F^\top F)^{-1} F^\top y$.

        >>> import jax, jax.numpy as jnp, lineax as lx, vardax as vdx
        >>> F = jnp.array([[1.0, 0.0], [0.0, 2.0], [1.0, 1.0]])
        >>> obs = vdx.CallableObs(fn=lambda x: x @ F.T)
        >>> obs(jnp.ones((1, 2))).shape
        (1, 3)
        >>> eye_x = lx.IdentityLinearOperator(jax.ShapeDtypeStruct((1, 2), jnp.float32))
        >>> eye_y = lx.IdentityLinearOperator(jax.ShapeDtypeStruct((1, 3), jnp.float32))
        >>> oi = vdx.OptimalInterpolation(
        ...     obs_op=obs,
        ...     prior_mean=jnp.zeros((1, 2)),
        ...     prior_cov_op=eye_x,
        ...     obs_cov_op=eye_y,
        ... )
        >>> y = jnp.array([1.0, 2.0, 3.0])
        >>> batch = vdx.Batch1D(input=y[None, None], mask=jnp.ones((1, 1, 3)))
        >>> blue = jnp.linalg.solve(jnp.eye(2) + F.T @ F, F.T @ y)
        >>> bool(jnp.allclose(oi(batch)[0, 0], blue, atol=1e-4))
        True

        A nonlinear map is linearised by autodiff, and ``materialise=True``
        forms the dense Jacobian:

        >>> sq = vdx.CallableObs(fn=lambda x: x**2, materialise=True)
        >>> jac = sq.linearize(jnp.array([1.0, 2.0, 3.0])).as_matrix()
        >>> bool(jnp.allclose(jac, jnp.diag(jnp.array([2.0, 4.0, 6.0]))))
        True
    """

    fn: Callable[[Float[Array, ...]], Float[Array, ...]]
    jac: Literal["fwd", "bwd"] | None = eqx.field(static=True, default=None)
    materialise: bool = eqx.field(static=True, default=False)

    def __call__(self, x: Float[Array, ...]) -> Float[Array, ...]:
        """Forward map $f(x)$.

        Args:
            x: State.

        Returns:
            The observation prediction $f(x)$.
        """
        return self.fn(x)

    def linearize(self, x: Float[Array, ...]) -> lx.AbstractLinearOperator:
        r"""Tangent-linear operator $H'(x) = \partial f / \partial x$ at ``x``.

        Args:
            x: State at which to linearise.

        Returns:
            A matrix-free ``JacobianLinearOperator``, or its dense
            materialisation when ``materialise=True``.
        """
        tangent = lx.JacobianLinearOperator(lambda z, _: self.fn(z), x, jac=self.jac)
        if self.materialise:
            # dense ∂f/∂x: one VJP per output (jac="bwd") or JVP per input
            return lx.materialise(tangent)
        return tangent

    class MaskedIdentity(eqx.Module):
    r"""$H(x) = m \odot x$ with optional element-wise mask.

    Stateless: no parameters. The mask can be supplied at call time
    (per-batch) rather than baked in.

    Examples:
        >>> import jax.numpy as jnp
        >>> import vardax as vdx
        >>> op = vdx.MaskedIdentity()
        >>> x = jnp.array([1.0, 2.0, 3.0])
        >>> op(x, mask=jnp.array([1.0, 0.0, 1.0]))
        Array([1., 0., 3.], dtype=float32)
        >>> type(op.linearize(x)).__name__
        'JacobianLinearOperator'

        Without a mask the operator is the identity:

        >>> bool(jnp.all(op(x) == x))
        True

        A per-batch mask broadcasts over the batch axis:

        >>> xb = jnp.ones((2, 3))
        >>> op(xb, mask=jnp.array([1.0, 0.0, 1.0])).sum(axis=-1)
        Array([2., 2.], dtype=float32)
    """

    def __call__(
        self,
        x: Float[Array, ...],
        mask: Float[Array, ...] | None = None,
    ) -> Float[Array, ...]:
        if mask is None:
            return x
        return x * mask

    def linearize(self, x: Float[Array, ...]) -> lx.AbstractLinearOperator:
        """Tangent-linear operator at ``x``: identity (since $H$ is linear).

        Args:
            x: State at which to linearise.

        Returns:
            An identity-like Jacobian operator on the shape of ``x``.
        """
        return lx.JacobianLinearOperator(lambda y, _args=None: y, x)

    class AveragingKernel(eqx.Module):
    r"""RTM L2-style averaging-kernel obs operator.

    $$H(x) = A \, (h \odot x + (1 - h) \odot x_a)$$

    Algorithm:
        1. Blend the state with the retrieval prior:
           $z = h \odot x + (1 - h) \odot x_a$.
        2. Apply the kernel: $\hat y = A z$.
        3. ``linearize`` returns $A \, \mathrm{diag}(h)$ without evaluating
           anything, because the map is affine in $x$.

    Attributes:
        kernel_matrix: Averaging kernel matrix, stored as an
            ``lineax.AbstractLinearOperator``. May be ``MatrixLinearOperator``
            for dense kernels or a structured operator (Kronecker for
            separable kernels, LowRank for retrievals with low DOF).
        prior_profile: Retrieval prior, same shape as the model state.
        pressure_weights: Weighting vector (often pressure-weighted).

    Examples:
        With $h = 1$ the prior drops out and the operator is just $A x$:

        >>> import jax.numpy as jnp, lineax as lx
        >>> import vardax as vdx
        >>> A = jnp.array([[0.5, 0.5], [0.0, 1.0]])
        >>> kernel = lx.MatrixLinearOperator(A)
        >>> op = vdx.AveragingKernel(
        ...     kernel_matrix=kernel,
        ...     prior_profile=jnp.zeros(2),
        ...     pressure_weights=jnp.ones(2),
        ... )
        >>> bool(jnp.allclose(op(jnp.array([1.0, 3.0])), A @ jnp.array([1.0, 3.0])))
        True

        Where $h = 0$ the output falls back to the retrieval prior $x_a$:

        >>> op0 = vdx.AveragingKernel(
        ...     kernel_matrix=kernel,
        ...     prior_profile=jnp.array([2.0, 2.0]),
        ...     pressure_weights=jnp.zeros(2),
        ... )
        >>> bool(jnp.allclose(op0(jnp.array([9.0, 9.0])), A @ jnp.array([2.0, 2.0])))
        True

        The tangent-linear operator is $A \, \mathrm{diag}(h)$:

        >>> bool(jnp.allclose(op.linearize(jnp.zeros(2)).as_matrix(), A))
        True

    def __call__(
        self,
        state: Float[Array, "*grid"],
        mask: Float[Array, " n_obs"] | None = None,
    ) -> Float[Array, " n_obs"]:
        """Apply ``H`` (optionally masked) to a grid state.

        Args:
            state: Grid state, either ``(ny, nx)`` or flattened.
            mask: Optional observation mask multiplying the predictions.

        Returns:
            The interpolated observations, one per location.
        """
        flat = flatten(state)
        corners = flat[self.indices]
        # yₒ = Σₖ wₒₖ x[iₒₖ]: bilinear weights over the four corners;
        # jnp, not einx: a time step may have no observations
        predicted_obs = jnp.sum(corners * self.weights, axis=-1)
        if mask is not None:
            predicted_obs = predicted_obs * mask
        return predicted_obs

        self,
        x: Float[Array, ...],
    ) -> lx.AbstractLinearOperator:

        derived via ``jax.vjp`` (cached numpy adjoint is no longer

            The operator $H$, which does not depend on ``x`` otherwise.

    Locates each observation in its grid cell and caches the four corner
    indices and bilinear weights. Points outside the grid are clamped to
    the edge.

        grid_coords: ``(y_axis, x_axis)`` tuple of 1-D axis arrays.

        NotImplementedError: If ``order`` is not 1.

    Examples:
        Cache the stencil for two observations on a 3 x 3 grid:

        >>> import jax.numpy as jnp
        >>> import vardax as vdx
        >>> axis = jnp.array([0.0, 1.0, 2.0])
        >>> obs = jnp.array([[0.5, 1.5], [2.0, 0.0]])
        >>> op = vdx.interp_obs_from_coords((axis, axis), obs)
        >>> op.indices.shape, op.weights.shape
        ((2, 4), (2, 4))

        Predict the observations from a state whose value is 3 * y + x:

        >>> op(jnp.arange(9.0).reshape(3, 3))
        Array([3., 6.], dtype=float32)

        A descending axis is rejected:

        >>> vdx.interp_obs_from_coords(
        ...     (axis[::-1], axis), obs
        ... )  # doctest: +IGNORE_EXCEPTION_DETAIL
        Traceback (most recent call last):
        ...
        GridError: y_axis must be strictly increasing ...
    """
    if order != 1:
        raise NotImplementedError(
            f"interp_obs_from_coords supports order=1 (bilinear), got {order}."
        )
    if len(grid_coords) != 2:
        raise GridError(
            "interp_obs_from_coords expects grid_coords=(y_axis, x_axis); "
            f"got len={len(grid_coords)}."
        )

    y_axis = _np.asarray(grid_coords[0], dtype=float)
    x_axis = _np.asarray(grid_coords[1], dtype=float)
    for name, axis in (("y_axis", y_axis), ("x_axis", x_axis)):
        if axis.size < 2 or _np.any(_np.diff(axis) <= 0):
            raise GridError(
                f"{name} must be strictly increasing with at least 2 points; "
                "reverse a descending axis before calling interp_obs_from_coords."
            )
    points = _np.asarray(obs_coords, dtype=float)
    if points.ndim != 2 or points.shape[1] != 2:
        raise ShapeError(f"obs_coords must be (n_obs, 2); got {points.shape}.")

    n_y, n_x = y_axis.size, x_axis.size
    y_lower_index, y_upper_weight = _bracket(y_axis, points[:, 0])
    x_lower_index, x_upper_weight = _bracket(x_axis, points[:, 1])
    y_upper_index, x_upper_index = y_lower_index + 1, x_lower_index + 1
    y_lower_weight, x_lower_weight = 1.0 - y_upper_weight, 1.0 - x_upper_weight

    # flat index of the 2x2 stencil: (lo, lo), (lo, hi), (hi, lo), (hi, hi)
    indices = _np.stack(
        [
            y_lower_index * n_x + x_lower_index,
            y_lower_index * n_x + x_upper_index,
            y_upper_index * n_x + x_lower_index,
            y_upper_index * n_x + x_upper_index,
        ],
        axis=1,
    )
    # bilinear weight of each corner, w_y w_x, in the same order
    weights = _np.stack(
        [
            y_lower_weight * x_lower_weight,
            y_lower_weight * x_upper_weight,
            y_upper_weight * x_lower_weight,
            y_upper_weight * x_upper_weight,
        ],
        axis=1,
    )

    return InterpObs(
        indices=jnp.asarray(indices, dtype=jnp.int32),
        # JAX's default float dtype, so the weights are float64 under x64
        weights=jnp.asarray(weights),
        grid_shape=(int(n_y), int(n_x)),
    )

    def __init__(self, grid_axes: tuple[Float[Array, " _"], ...]) -> None:
        axes = tuple(jnp.asarray(axis_values) for axis_values in grid_axes)
        if len(axes) not in (1, 2):
            raise GridError(f"grid_axes must hold 1 or 2 axes; got {len(axes)}.")
        for axis_number, axis in enumerate(axes):
            if axis.ndim != 1 or axis.shape[0] < 2:
                raise GridError(
                    f"grid_axes[{axis_number}] must be 1-D with at least 2 points; "
                    f"got shape {axis.shape}."
                )
            if not bool(jnp.all(jnp.diff(axis) > 0)):
                raise GridError(
                    f"grid_axes[{axis_number}] must be strictly increasing."
                )
        self.grid_axes = axes

    def __call__(
        self, state: Float[Array, "n_times ..."], batch: PointObsBatch
    ) -> Float[Array, " N_obs"]:
        r"""Interpolate ``state[time_index]`` at the observation coordinates.

        Args:
            state: Gridded state with a leading time axis.
            batch: The point observations.

        Returns:
            The interpolated prediction $\hat y_i$ for every row,
            padding included.
        """
        safe = _safe(batch)
        n_obs = safe.values.shape[0]
        grid_shape = tuple(axis.shape[0] for axis in self.grid_axes)
        flat_frames = einx.id("t s... -> t (s...)", state)
        frames = einx.id("t (g...) -> t g...", flat_frames, g=grid_shape)
        time_indices = (
            jnp.zeros(n_obs, dtype=jnp.int32)
            if safe.time_index is None
            else jnp.clip(safe.time_index, 0, state.shape[0] - 1)
        )
        if len(self.grid_axes) == 1:
            left_index, right_weight = _bracket(self.grid_axes[0], safe.coords[:, 0])
            left = frames[time_indices, left_index]
            right = frames[time_indices, left_index + 1]
            # ŷ = (1 − w) f_left + w f_right
            return (1.0 - right_weight) * left + right_weight * right
        y_index, y_weight = _bracket(self.grid_axes[0], safe.coords[:, 0])
        x_index, x_weight = _bracket(self.grid_axes[1], safe.coords[:, 1])
        corner_00 = frames[time_indices, y_index, x_index]
        corner_01 = frames[time_indices, y_index, x_index + 1]
        corner_10 = frames[time_indices, y_index + 1, x_index]
        corner_11 = frames[time_indices, y_index + 1, x_index + 1]
        # ŷ = (1 − w_y) [(1 − w_x) f₀₀ + w_x f₀₁] + w_y [(1 − w_x) f₁₀ + w_x f₁₁]
        return (1.0 - y_weight) * (
            (1.0 - x_weight) * corner_00 + x_weight * corner_01
        ) + y_weight * ((1.0 - x_weight) * corner_10 + x_weight * corner_11)

        >>> obs = {"a": jnp.array([1.0, 2.0]), "b": jnp.array([4.0])}
        >>> float(weighted.cost(jnp.zeros(2), obs))  # ½ (1 + 4) + 2 · ½ 16
        18.5
        >>> weighted.obs_cov_op().as_matrix().diagonal().tolist()
        [1.0, 1.0, 0.5]
    """

    registry: InstrumentRegistry
    weights: dict[str, float] | None = None

    def __call__(self, x: Float[Array, ...]) -> dict[str, Float[Array, ...]]:
        """Apply every instrument operator to the same state.

        Args:
            x: State shared by all instruments.

        Returns:
            Predicted observations keyed by instrument id.
        """
        return {
            inst_id: spec.obs_op(x) for inst_id, spec in self.registry.entries.items()
        }

    def linearize(self, x: Float[Array, ...]) -> dict[str, lx.AbstractLinearOperator]:
        """Per-instrument tangent-linear operators.

        Returns ``{instrument_id: H_i'(x)}``. The fused tangent linear
        is the block-diagonal stack of these — assembled lazily by
        the cost function or via ``to_observation_operator()``.

        Args:
            x: State at which to linearise.
        """
        return {
            inst_id: spec.obs_op.linearize(x)
            for inst_id, spec in self.registry.entries.items()
        }

    def weight(self, instrument_id: str) -> float:
        """The weight $\alpha_i$ of one instrument, ``1`` unless given.

        Args:
            instrument_id: Key of the instrument in the registry.

        Returns:
            ``weights[instrument_id]``, or ``1.0``.
        """
        if self.weights is None:
            return 1.0
        return self.weights.get(instrument_id, 1.0)

    def cost(
        self,
        x: Float[Array, ...],
        observations: dict[str, Float[Array, ...]],
        solver: lx.AbstractLinearSolver | None = None,
    ) -> Float[Array, ""]:
        r"""Fused observation cost of the state ``x``.

        $$J_\text{obs}(x) = \sum_i \alpha_i \tfrac12
        \|m_i \odot (y_i - H_i(x))\|^2_{R_i^{-1}}$$

        Masked-out cells may hold ``NaN``; they are ignored.

        Args:
            x: State shared by all instruments.
            observations: Observations $y_i$ keyed by instrument id, one
                for every instrument in the registry.
            solver: Linear solver for $R_i^{-1} r_i$. Default ``None``:
                ``lx.AutoLinearSolver(well_posed=True)``, a direct solve
                (closed form for a diagonal $R_i$).

        Returns:
            The scalar cost.
        """
        solver = solver or lx.AutoLinearSolver(well_posed=True)
        total = jnp.zeros(())
        for inst_id, spec in self.registry.entries.items():
            observed = fill_gaps(observations[inst_id], spec.mask)
            # rᵢ = mᵢ ⊙ (yᵢ − Hᵢ(x))
            residual = spec.mask * (observed - spec.obs_op(x))
            # Rᵢ⁻¹ rᵢ
            weighted = lx.linear_solve(
                as_covariance(spec.obs_cov_op), residual, solver=solver
            ).value
            # αᵢ ½ rᵢᵀ Rᵢ⁻¹ rᵢ
            total = total + self.weight(inst_id) * 0.5 * jnp.sum(residual * weighted)
        return total

    def obs_cov_op(self) -> lx.AbstractLinearOperator:
        r"""Block-diagonal $R$ of the flattened observations, blocks $R_i / \alpha_i$.

        Blocks follow the sorted instrument order of
        ``to_observation_operator()``, so a model given both minimises the
        weighted fused cost.

        Returns:
            A lazy PSD operator on the concatenated observation vector.
        """
        ids = sorted(self.registry.entries)
        covs = [self.registry.entries[k].obs_cov_op for k in ids]
        shapes = [cov.in_structure().shape for cov in covs]
        sizes = [int(jnp.prod(jnp.array(shape))) for shape in shapes]
        dtype = covs[0].in_structure().dtype if covs else jnp.float32
        flat = jax.ShapeDtypeStruct((sum(sizes),), dtype)

        def covariance_mv(vector: Float[Array, " M"]) -> Float[Array, " M"]:
            blocks = []
            offset = 0
            for inst_id, cov, shape, size in zip(ids, covs, shapes, sizes, strict=True):
                segment = vector[offset : offset + size].reshape(shape)
                # Rᵢ vᵢ / αᵢ
                block = cov.mv(segment) / self.weight(inst_id)
                blocks.append(jnp.ravel(block))
                offset += size
            return jnp.concatenate(blocks)

        return lx.FunctionLinearOperator(
            covariance_mv, flat, lx.positive_semidefinite_tag
        )

    def to_observation_operator(self) -> _FlattenedMultiInstrument:
        """Adapt to the strict ``pipekit_cycle.ObservationOperator`` protocol.

        Returns a wrapper that concatenates per-instrument outputs and
        exposes a block-diagonal linear operator. Use this when the
        consumer requires a single ``(state) -> Array`` signature.
        """
        return _FlattenedMultiInstrument(fusion=self)
