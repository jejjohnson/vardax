Lorenz Examples

The Lorenz systems are the canonical small-scale testbeds for DA. Their chaotic dynamics expose what each method does well or badly in a setting where ground truth is available, integration is cheap, and the state dimension is small enough to visualise.

This chapter walks the seven analysis methods through Lorenz-63 (3D chaotic system) and Lorenz-96 (40D periodic system). The goal is to make each method’s behaviour concrete.

Lorenz-63¶

The Lorenz-63 system is

x˙=σ(y−x),y˙=x(ρ−z)−y,z˙=xy−βz,\dot{x} = \sigma(y - x), \dot{y} = x(\rho - z) - y, \dot{z} = xy - \beta z,x˙=σ(y−x),y˙​=x(ρ−z)−y,z˙=xy−βz,
(15.1)

where (x,y,z)(x, y, z)(x,y,z) is the state and σ\sigmaσ, ρ\rhoρ, β\betaβ are its three parameters, here the canonical (10,28,8/3)(10, 28, 8/3)(10,28,8/3). The state dimension is n=3n = 3n=3, and the dynamics live on the famous two-winged attractor.

The code on this page runs top to bottom as one script; each block continues the one above. The keys for every stochastic stage are split once, here.

It prints (5001, 3); the default burn-in of 1,000 steps is dropped.

Synthetic observation scenario¶

Take one window of W=101W = 101W=101 steps (one time unit, about one Lyapunov time) and observe it every k=10k = 10k=10 steps, with Gaussian noise of standard deviation σo=1\sigma_o = 1σo​=1. The data utilities are private helpers under vardax._src.utils, which the tutorial notebooks also use. xr_to_batch1d expects a patch dimension, so the window gets one.

OptimalInterpolation won’t work directly¶

OI (chapter 4) assumes a static Gaussian field, which the nonlinear Lorenz dynamics violate. So OI with the climatological mean xˉ\bar{x}xˉ and covariance CCC of the trajectory as its prior gives a poor reconstruction, but it is a useful baseline. Each time is treated separately, with B=CB = CB=C and R=IR = IR=I.

It prints OI trajectory RMSE 6.06.

StrongFourDVar is the right tool¶

The background xbx_bxb​ is the true initial state plus noise of standard deviation σb=2\sigma_b = 2σb​=2, and the prior B=100IB = 100 IB=100I is deliberately weak. HtH_tHt​ is the masked identity and R=IR = IR=I.

It prints strong 4DVar trajectory RMSE 0.28.

Diagnostic: plot the attractor reconstruction. StrongFourDVar recovers the butterfly; OptimalInterpolation smears across both wings because the static prior doesn’t know about the dynamics.

FourDVarNet for the learned-prior comparison¶

Train a small AE prior on short patches of the training trajectory. Two epochs of vardax.examples.fit_demo only show the plumbing; notebook 03 trains it properly.

It prints (8, 20, 3).

FourDVarNet1D learns the attractor structure from the training data and reconstructs without explicit access to the dynamics. The comparison strong_analysis vs net_analysis is the canonical demonstration that learned priors recover similar information to model-based ones.

Lorenz-96¶

The Lorenz-96 system is a one-dimensional periodic version:

X˙k=(Xk+1−Xk−2)Xk−1−Xk+F, for k=0,…,N−1,\dot{X}_k = (X_{k+1} - X_{k-2}) X_{k-1} - X_k + F, \text{ for } k = 0, \ldots, N-1,X˙k​=(Xk+1​−Xk−2​)Xk−1​−Xk​+F, for k=0,…,N−1,
(15.2)

where XkX_kXk​ is the state at site kkk of a periodic ring (indices taken modulo NNN) and FFF is the forcing. We use N=40N = 40N=40 and F=8F = 8F=8, which is the chaotic regime. The state is a periodic 1D field, closer in structure to atmospheric problems than Lorenz-63.

It prints (5001, 40).

IncrementalFourDVar with structured Matérn prior¶

This is the realistic operational scenario: structured spatial prior, incremental solver (chapter 8), AK-style or masked observations.

The Matérn-3/2 covariance on the periodic grid depends only on the ring distance dij=min⁡(∣i−j∣,K−∣i−j∣)d_{ij} = \min(|i - j|, K - |i - j|)dij​=min(∣i−j∣,K−∣i−j∣), so it is circulant; here it is a dense 40×4040 \times 4040×40 matrix. gaussx.Toeplitz would store it by its first column; the dense matrix keeps the example short. The forward model is one RK4 step written on the page, which forward- and reverse-mode autodiff both see through, as the Gauss-Newton loop needs. The background is the true initial state plus noise drawn from the same scale as BBB.

It prints background error 5.76, analysis error 2.98 and (40,), the errors being in x0x_0x0​.

This walkthrough exercises the periodic Matérn prior as a lineax operator, the CVT (8.6) with B1/2B^{1/2}B1/2 from the Matérn factorisation, and the Gauss-Newton and CG loop (8.5), whose Hessian (8.4) the posterior reuses for free.

The reconstruction recovers the Lorenz-96 trajectory through gaps, with calibrated posterior uncertainty in unobserved regions.

Linear-Gaussian agreement test¶

Lorenz dynamics aren’t linear, but we can construct a static linear-Gaussian test on the Lorenz-63 attractor by treating the trajectory mean as the prior and the empirical covariance as BBB.

With M(x)=xM(x) = xM(x)=x over one time, the BLUE mean (4.4) and the minimisers of (5.1), (6.1) and (8.3) are the same point. Only the four classical methods take this batch; FourDVarNet is left out, as in tests/test_linear_gaussian_agreement.py, because its learned components must be trained before they can match.

It prints agrees with OI: True for all four methods.

This is the Decision D14 invariant in action.
