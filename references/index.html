Ecosystem libraries¶

  • somax — geophysical fluid models

  • plumax — atmospheric transport + RTM (methane)

  • gaussx — structured linear operators, Matérn factorisation

  • lineax — linear solvers, AbstractLinearOperator

  • optimistix — optimisers + adjoints

  • diffrax — ODE / SDE integration + adjoints

  • filterax — ensemble methods

  • pipekit + pipekit-cycle — operator composition + DA cycle protocols
