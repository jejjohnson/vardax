# Adjoint Methods

Every analysis method that involves minimisation or dynamics needs
gradients. For 4DVar, that's gradients through the ODE rollout. For
`FourDVarNet`, that's gradients through the inner learned solver. For
training amortized heads, it's standard backprop.

Vardax does not own adjoint code. Gradients through dynamics come from
`diffrax.AbstractAdjoint`; gradients through inner minimisers come
from `optimistix.AbstractAdjoint` (Decision D15). This chapter
explains the choices and when to use which.

## Why composable adjoints

Historical DA libraries hand-coded adjoint models: every forward operator $f_t$ required a hand-written companion $\mat{F}_t^\top$, often generated by automatic-differentiation source-to-source transformations (TAMC, OpenAD), and maintaining the adjoint code as the forward evolved was a significant engineering tax.

JAX changed the picture by making reverse-mode autodiff a first-class
language feature. `diffrax` and `optimistix` build on this by exposing
**named adjoint strategies** as user-selectable types. The user
chooses between memory and time, between exact and approximate; the
library handles the differentiation.

Vardax exposes these strategies as constructor slots on the Layer 2 models, with no vardax-owned `grad_mode` enum and no in-house adjoint implementation.

## Adjoints through dynamics (`diffrax.AbstractAdjoint`)

For 4DVar with dynamics, the cost is the strong-constraint cost [](#eq-strong4dvar-cost), and its gradient [](#eq-strong4dvar-grad) pulls the observation misfits back through the adjoint $\mat{F}_t^\top$ of every step of the rollout. Write $N_\text{step}$ for the number of integration steps of a `diffeqsolve` call and $D_x$ for the state length. `diffrax.diffeqsolve(..., adjoint=...)` computes that pull-back, and there are four choices.

### `RecursiveCheckpointAdjoint(checkpoints=N)`, the default

Recursive checkpointing of the forward trajectory. Stores $N_\text{ckpt} \sim \log N_\text{step}$
checkpoints; recomputes intermediate states from checkpoints during the
backward pass.

| Memory | Time | When |
|---|---|---|
| $O(\log N_\text{step})$ | $O(N_\text{step} \log N_\text{step})$ | Default. Balanced. |

The default $N_\text{ckpt} = \lceil \log_2 N_\text{step} \rceil + 1$, the `checkpoints` argument, is usually right. Override
only if profiling shows memory pressure.

### `BacksolveAdjoint()`, the continuous adjoint

Solve the adjoint ODE backwards in time. The adjoint state $\vect{x}^\dagger(t) \in \mathbb{R}^{D_x}$ satisfies

$$\frac{\mathrm{d}\vect{x}^\dagger}{\mathrm{d}t} = -\mat{F}(t)^\top \vect{x}^\dagger(t) - \nabla_{\vect{x}(t)} \mathcal{J}_o$$ (eq-adjoint-ode)

where $\mat{F}(t) \in \mathbb{R}^{D_x \times D_x}$ is the Jacobian of the vector field $f$ of $\mathrm{d}\vect{x}/\mathrm{d}t = f(t, \vect{x})$ along the forward trajectory $\vect{x}(t)$ and $\nabla_{\vect{x}(t)} \mathcal{J}_o \in \mathbb{R}^{D_x}$ is the forcing from the observation misfit at time $t$. It is integrated from $t = T$ to $t = 0$ and is the continuous-time counterpart of the discrete recursion [](#eq-adjoint-recursion): read backwards in time, the misfit forcing adds to $\vect{x}^\dagger$. Because the forward state is recomputed during that backward solve, the memory is constant in the length of the trajectory.

| Memory | Time | When |
|---|---|---|
| $O(1)$ | $\sim 2 \times$ forward | Long windows, memory-constrained |

Caveat: reverse-time stiffness. If the forward ODE is well-conditioned
with an explicit integrator, the backward might be stiff. Use
`dfx.Kvaerno5` or `dfx.ImplicitEuler` for the adjoint if so.

### `ForwardMode()`, forward sensitivity

Compute gradients with forward-mode autodiff, which solves the sensitivity ODEs forward in time alongside the state.

| Memory | Time | When |
|---|---|---|
| $O(D_\theta)$ | $O(D_\theta) \times$ forward | Few parameters ($D_\theta$ small) |

Use it when you differentiate with respect to a small number of parameters $\gvect{\theta} \in \mathbb{R}^{D_\theta}$ (e.g. a single emission rate $q$ in methane Tier I). Forward mode wins when $D_\theta \ll D_x$ (the state dimension); reverse mode wins when $D_\theta \gg 1$.

### `DirectAdjoint()`, plain reverse

Standard reverse-mode autodiff through the `lax.scan` of integration
steps. No checkpointing.

| Memory | Time | When |
|---|---|---|
| $O(N_\text{step})$ | $O(N_\text{step})$ | Short windows; debugging |

Slow but transparent. It is useful when debugging adjoint issues, because the gradient is literally the reverse-mode autodiff result with no clever tricks.

## Adjoints through inner minimisers (`optimistix.AbstractAdjoint`)

For methods that train through an inner minimisation (`FourDVarNet`,
`AmortizedPosterior`, or any classical method whose hyperparameters are
themselves trained), the training gradient flows through
`optimistix.minimise(...)` via its `adjoint` argument.

### `RecursiveCheckpointAdjoint()`

Unroll the inner iteration with checkpointing. Standard backprop
through the iterative solver. Used by `FourDVarNet` for end-to-end
training when memory permits.

| Memory | Convergence requirement |
|---|---|
| $O(N_\text{iter})$ checkpoints | None |

### `ImplicitAdjoint()`, the implicit function theorem at the optimum

At the optimum $\vect{x}^\star$ of $\min_{\vect{x}} \mathcal{J}(\vect{x}; \gvect{\theta})$, the implicit function theorem gives

$$\frac{\partial \vect{x}^\star}{\partial \gvect{\theta}} = -\left( \nabla^2_{\vect{x}} \mathcal{J}(\vect{x}^\star; \gvect{\theta}) \right)^{-1} \nabla^2_{\vect{x} \gvect{\theta}} \mathcal{J}(\vect{x}^\star; \gvect{\theta})$$ (eq-implicit-grad)

where $\mathcal{J}$ is the inner objective (a cost such as [](#eq-3dvar-cost)), $\vect{x} \in \mathbb{R}^{D_x}$ the inner control and $\gvect{\theta} \in \mathbb{R}^{D_\theta}$ the outer parameters being trained. The Hessian is $D_x \times D_x$, the mixed derivative $\nabla^2_{\vect{x} \gvect{\theta}} \mathcal{J}$ is $D_x \times D_\theta$ and so is $\partial \vect{x}^\star / \partial \gvect{\theta}$. `optimistix` solves this system implicitly: it never inverts the Hessian, and uses `lineax` to apply $(\nabla^2_{\vect{x}} \mathcal{J})^{-1}$ to vectors.

| Memory | Convergence requirement |
|---|---|
| $O(1)$ | Yes (must reach optimum) |

Used by classical methods (`ThreeDVar`, `StrongFourDVar`, `WeakFourDVar`) when training hyperparameters. The exact-at-optimum property is the right model here, since at a well-converged MAP [](#eq-implicit-grad) gives the correct sensitivity.

### `DirectAdjoint()`

optimistix ships no `DirectAdjoint`; its only adjoints are `RecursiveCheckpointAdjoint` and `ImplicitAdjoint`. Plain reverse through the solver loop is `optx.RecursiveCheckpointAdjoint()`, and `to_optimistix_adjoint` rejects a `DirectAdjoint` spec for that reason.

### `argminax.adjoint.OneStep()` (Bolte et al. 2023)

The one-step adjoint of argminax, the stack's home for minimiser adjoints; `vardax.adjoints.OneStepAdjoint` is a deprecated alias of it.

| Memory | Convergence requirement |
|---|---|
| $O(1)$ | Approximately convergent |

It runs $N_\text{iter} - 1$ inner iterations under `jax.lax.stop_gradient`, then a single differentiable step, so the training gradient picks up only the last step's contribution. Bolte et al. prove this is exact at the fixed point (the fixed-point gradient [](#eq-fixed-point-grad)); in practice it gives near-correct gradients for converged inner solvers and reduces memory a lot.

The example builds a `FourDVarNet1D` for $S = 2$ windows of $T = 3$ steps, so $T + 1 = 4$ times, and $D_x = 8$ cells, fed with standard-normal observations $\vect{y}$, and runs its $N_\text{iter} = 15$ learned solver steps (the update [](#eq-4dvarnet-update)) under `OneStepAdjoint`. The PRNG keys for the whole page are split here.

```{code-block} python
:caption: Runs the learned solver steps of [](#eq-4dvarnet-update) under `OneStepAdjoint` on two toy windows.
:label: code-adjoints-one-step
import argminax as amx
import jax
import jax.numpy as jnp
import vardax as vdx

# Shapes: S = 2 windows; T = 3 steps, so T + 1 = 4 times; D_x = 8 state cells;
# N_iter = 15 solver steps

key = jax.random.PRNGKey(0)
key_net, key_obs, key_truth, key_noise = jax.random.split(key, 4)

# y ~ 𝒩(0, I), every cell observed
obs = jax.random.normal(key_obs, (2, 4, 8))  # (S, T+1, D_x)
# today (vardax)
batch = vdx.Batch1D(input=obs, mask=jnp.ones((2, 4, 8)))
# today (vardax)
# N_iter − 1 steps under stop_gradient, then one differentiable step: O(1) memory
model = vdx.FourDVarNet1D(
    state_dim=8,
    n_time=4,
    latent_dim=8,
    hidden_dim=16,
    solver_adjoint=amx.adjoint.OneStep(),
    key=key_net,
)
# x⋆ = x⁽N_iter⁾, N_iter learned solver steps from y
reconstruction = model(batch)  # (S, T+1, D_x) → (S, T+1, D_x)
print(reconstruction.shape)
```

It prints `(2, 4, 8)`.

`OneStep` is an `optimistix.AbstractAdjoint` subclass that lives in argminax (vardax#278), where its `apply` is implemented, so it also works under any `optx.minimise` or `optx.least_squares` call. vardax's `OneStepAdjoint` and `KStepAdjoint` are deprecated aliases that warn once and are removed in the next release.

## Slots and where they apply

Vardax models that involve both dynamics and inner minimisation carry
separate slots for the two:

| Slot | Used by | Default |
|---|---|---|
| `checkpoint: bool \| int` | `StrongFourDVar`, `WeakFourDVar`, `IncrementalFourDVar`, `ReducedBasisFourDVar` | `False` (plain reverse mode) |
| `forward_adjoint: diffrax.AbstractAdjoint` | the same four; needs a forward with `with_adjoint` ([`SupportsForwardAdjoint`](xref:api#vardax.SupportsForwardAdjoint)) | `None` (the forward's own) |
| `minimiser_adjoint: optimistix.AbstractAdjoint` | `ThreeDVar`, `StrongFourDVar`, `WeakFourDVar`, `ReducedBasisFourDVar` | `ImplicitAdjoint()` |
| `solver_adjoint: optimistix.AbstractAdjoint` | `FourDVarNet1D`, `FourDVarNet2D` (through the learned inner solver) | `RecursiveCheckpointAdjoint()` |

`checkpoint` and `forward_adjoint` act on the dynamics rollout;
`minimiser_adjoint` and `solver_adjoint` act on the inner minimisation.
They are independent.

- `checkpoint=True` runs the rollout through `integrix.adjoint.checkpointed_scan`, which wraps each step in `jax.checkpoint` (an integer `k` wraps blocks of `k` steps), so reverse mode recomputes the steps instead of storing their intermediates. It works for any per-step forward and leaves the gradient unchanged.
- `forward_adjoint=` is handed to `forward.with_adjoint(adjoint)`, which
  a `diffrax`-backed forward implements by passing the adjoint to
  `diffeqsolve` (chapter 3). With a forward that has no `with_adjoint`,
  the model raises `ValueError` at construction rather than ignoring the
  slot. It takes a diffrax adjoint, not `integrix.adjoint.Checkpointed`, whose rollout counterpart is `checkpoint=`.

A typical operational 4DVar configuration has a `diffrax`-backed forward. The forward below integrates $\mathrm{d}\vect{x}/\mathrm{d}t = -\kappa \vect{x}$ with $\kappa = 0.1$ over one step $\Delta t = 1$ with `diffrax`, and implements `with_adjoint` by storing the adjoint it is handed. The window has $T = 3$ steps, so $T + 1 = 4$ times, of all $D_x = 8$ cells, observed with $\gmat{\Sigma}_\varepsilon = \sigma^2 \mat{I}$, $\sigma = 0.1$, around a truth $\vect{x}_0 \sim \mathcal{N}(\mathbf{0}, \mat{I})$; the background is $\gvect{\mu}_x = \mathbf{0}$ with $\gmat{\Sigma}_x = \mat{I}$. The block continues the one above.

```{code-block} python
:caption: Minimises the strong-constraint cost [](#eq-strong4dvar-cost) with its gradient [](#eq-strong4dvar-grad) pulled back by the adjoint ODE [](#eq-adjoint-ode) inside every `diffeqsolve`.
:label: code-adjoints-backsolve
import diffrax as dfx
import einx
import equinox as eqx
import lineax as lx
import optimistix as optx
from jaxtyping import Array, Float

# Shapes: S = 1 window; T = 3 steps, so T + 1 = 4 times; D_x = 8 state cells


# user
class DiffraxDecay(eqx.Module):
    """dx/dt = −κ x, integrated over one step with diffrax."""

    rate: float = eqx.field(static=True, default=0.1)
    dt: float = eqx.field(static=True, default=1.0)
    adjoint: dfx.AbstractAdjoint = dfx.RecursiveCheckpointAdjoint()

    def step(self, state: Float[Array, " n"], dt: float) -> Float[Array, " n"]:
        # today (diffrax)
        # dx/dt = −κ x
        decay_term = dfx.ODETerm(lambda t, x, args: -self.rate * x)
        # today (diffrax)
        # x(t + Δt) = x(t) + ∫ −κ x dt
        solution = dfx.diffeqsolve(
            decay_term,
            dfx.Tsit5(),
            t0=0.0,
            t1=dt,
            dt0=0.1,
            y0=state,
            adjoint=self.adjoint,
        )
        return solution.ys[-1]  # (1, D_x) → (D_x,)

    def with_adjoint(self, adjoint: dfx.AbstractAdjoint) -> "DiffraxDecay":
        # today (equinox)
        return eqx.tree_at(lambda forward: forward.adjoint, self, adjoint)


state_structure = jax.ShapeDtypeStruct((8,), jnp.float32)
# Σ_x = I
prior_cov = lx.IdentityLinearOperator(state_structure)  # (D_x, D_x) op
# Σ_ε = σ² I, σ = 0.1
scaled_identity = jnp.float32(0.01) * prior_cov  # (D_x, D_x) op
# tagged PSD so the default CG solve accepts it
obs_cov = lx.TaggedLinearOperator(  # (D_x, D_x) op
    scaled_identity, lx.positive_semidefinite_tag
)
# μ_x = 0
background = jnp.zeros(8)  # (D_x,)
# x₀ ~ 𝒩(0, I)
truth = jax.random.normal(key_truth, (8,))  # (D_x,)
# t = 0 … T
observation_times = jnp.arange(4.0)  # (T+1,)
# e^{−κ t}
decay_factors = jnp.exp(-0.1 * observation_times)  # (T+1,)
# xₜ = e^{−κ t} x₀
truth_trajectory = einx.multiply(  # (T+1, D_x)
    "t, n -> t n", decay_factors, truth
)
# εₜ ~ 𝒩(0, I)
obs_noise = jax.random.normal(key_noise, (4, 8))  # (T+1, D_x)
# yₜ = xₜ + σ εₜ
window_obs = truth_trajectory + 0.1 * obs_noise  # (T+1, D_x)
window_input = einx.id(  # (T+1, D_x) → (S, T+1, D_x)
    "t n -> 1 t n", window_obs
)
# today (vardax)
window = vdx.Batch1D(input=window_input, mask=jnp.ones((1, 4, 8)))

# today (vardax)
# x₀⋆ = argmin 𝒥(x₀), backsolve adjoint through every diffeqsolve
strong_backsolve = vdx.StrongFourDVar(
    forward=DiffraxDecay(),
    obs_op=vdx.MaskedIdentity(),
    prior_mean=background,
    prior_cov_op=prior_cov,
    obs_cov_op=obs_cov,
    minimiser=optx.NonlinearCG(rtol=1e-5, atol=1e-5),
    minimiser_adjoint=optx.ImplicitAdjoint(),
    forward_adjoint=dfx.BacksolveAdjoint(),
)
analysis = strong_backsolve(window)  # (S, T+1, D_x) → (S, D_x)

# ‖μ_x − x₀‖
background_misfit = background - truth  # (D_x,)
background_error = jnp.linalg.norm(background_misfit)  # → ()
# ‖x₀⋆ − x₀‖
analysis_misfit = analysis[0] - truth  # (D_x,)
analysis_error = jnp.linalg.norm(analysis_misfit)  # → ()
print(f"background error {background_error:.2f}, analysis error {analysis_error:.2f}")
```

It prints `background error 2.31, analysis error 0.13`.

With a per-step forward (an RK4 stepper, a learned emulator), bound the rollout memory with `checkpoint=` instead. Here the same decay is one classical RK4 step per $\Delta t$, and `checkpoint=2` rematerialises the rollout in blocks of two steps. The block continues the one above.

```{code-block} python
:caption: Minimises [](#eq-strong4dvar-cost) with an RK4 forward and a checkpointed rollout for the reverse-mode gradient [](#eq-strong4dvar-grad).
:label: code-adjoints-checkpoint
# Shapes: S = 1 window; T = 3 steps, so T + 1 = 4 times; D_x = 8 state cells


# user
class RK4Decay(eqx.Module):
    """dx/dt = −κ x, one classical Runge-Kutta step per call."""

    rate: float = eqx.field(static=True, default=0.1)
    dt: float = eqx.field(static=True, default=1.0)

    def step(self, state: Float[Array, " n"], dt: float) -> Float[Array, " n"]:
        # ẋ₁ = f(x), f(x) = −κ x
        slope_1 = -self.rate * state
        # ẋ₂ = f(x + ½ Δt ẋ₁)
        slope_2 = -self.rate * (state + 0.5 * dt * slope_1)
        # ẋ₃ = f(x + ½ Δt ẋ₂)
        slope_3 = -self.rate * (state + 0.5 * dt * slope_2)
        # ẋ₄ = f(x + Δt ẋ₃)
        slope_4 = -self.rate * (state + dt * slope_3)
        # x + Δt (ẋ₁ + 2 ẋ₂ + 2 ẋ₃ + ẋ₄) / 6
        return state + dt / 6 * (slope_1 + 2 * slope_2 + 2 * slope_3 + slope_4)


# today (vardax)
# x₀⋆ = argmin 𝒥(x₀), rollout rematerialised in blocks of two steps
strong_checkpointed = vdx.StrongFourDVar(
    forward=RK4Decay(),
    obs_op=vdx.MaskedIdentity(),
    prior_mean=background,
    prior_cov_op=prior_cov,
    obs_cov_op=obs_cov,
    checkpoint=2,
)
checkpointed_analysis = strong_checkpointed(window)  # (S, T+1, D_x) → (S, D_x)
# the RK4 forward reaches the diffrax analysis
print(bool(jnp.allclose(checkpointed_analysis, analysis, atol=1e-3)))
```

It prints `True`.

In a typical 4DVarNet training configuration the learned solver has no dynamics rollout, so its memory is set by `solver_adjoint`. The training loss is the mean squared reconstruction error $\mathcal{L}(\gvect{\theta})$ of the network parameters $\gvect{\theta}$ against a target $\vect{x}$, here the observations themselves (a stand-in for the 4DVarNet loss [](#eq-4dvarnet-loss)); its gradient flows through the solver by `OneStepAdjoint`. The block continues the ones above.

```{code-block} python
:caption: Differentiates a reconstruction loss standing in for [](#eq-4dvarnet-loss) through the `OneStepAdjoint` solver.
:label: code-adjoints-training-gradient
# Shapes: S = 2 windows; T = 3 steps, so T + 1 = 4 times; D_x = 8 state cells


# user
def reconstruction_loss(network: vdx.FourDVarNet1D) -> Float[Array, ""]:
    # x⋆ = x⁽N_iter⁾
    estimate = network(batch)  # (S, T+1, D_x)
    # x⋆ − x
    misfit = estimate - obs  # (S, T+1, D_x)
    # (x⋆ − x)²
    squared_misfit = misfit**2  # (S, T+1, D_x)
    # ℒ(θ) = mean ‖x⋆ − x‖²
    loss = einx.mean("[s t n]", squared_misfit)  # (S, T+1, D_x) → ()
    return loss


# today (equinox)
loss_grad_fn = eqx.filter_grad(reconstruction_loss)
# ∇_θ ℒ, O(1) training memory through the solver
loss_gradient = loss_grad_fn(model)
# today (equinox)
gradient_arrays = eqx.filter(loss_gradient, eqx.is_array)
gradient_leaves = jax.tree.leaves(gradient_arrays)
is_finite = [bool(jnp.isfinite(leaf).all()) for leaf in gradient_leaves]
print(len(gradient_leaves), all(is_finite))
```

It prints `12 True`: twelve parameter arrays, each with a finite gradient.

## Validation: do they agree?

All adjoint choices should produce the same gradient (up to floating-point tolerance) for converged problems. The check below uses $\gmat{\Sigma}_x = \gmat{\Sigma}_\varepsilon = \mat{I}$, $\mat{H}_t = \mat{I}$ and the decay dynamics above under each of the four `diffrax` adjoints; `ForwardMode` needs forward-mode autodiff, so it goes through `jax.jacfwd`. The block continues the ones above.

```{code-block} python
:caption: Computes the gradient [](#eq-strong4dvar-grad) of the window cost [](#eq-strong4dvar-cost) under each of the four `diffrax` adjoints and compares them.
:label: code-adjoints-agreement
# Shapes: T = 3 steps, so T + 1 = 4 times; D_x = 8 state cells


# user
def decay_field(
    time: float, state: Float[Array, " n"], args: None
) -> Float[Array, " n"]:
    # f(x) = −κ x, κ = 0.1
    return -0.1 * state


# user
def window_cost(
    initial_state: Float[Array, " n"], adjoint: dfx.AbstractAdjoint
) -> Float[Array, ""]:
    # today (diffrax)
    # dx/dt = f(x)
    decay_term = dfx.ODETerm(decay_field)
    # today (diffrax)
    # x(t) for t = 0 … T, from x(0) = x₀
    solution = dfx.diffeqsolve(
        decay_term,
        dfx.Tsit5(),
        t0=0.0,
        t1=3.0,
        dt0=0.1,
        y0=initial_state,
        saveat=dfx.SaveAt(ts=observation_times),
        adjoint=adjoint,
    )
    # δx = x₀ − μ_x
    increment = initial_state - background  # (D_x,)
    # rₜ = yₜ − x(t)
    misfit = window_obs - solution.ys  # (T+1, D_x)
    # ½ δxᵀ δx
    background_term = 0.5 * einx.dot("n, n ->", increment, increment)  # → ()
    # ½ ∑ₜ rₜᵀ rₜ
    obs_term = 0.5 * einx.dot("t n, t n ->", misfit, misfit)  # → ()
    # 𝒥(x₀) = ½ δxᵀ δx + ½ ∑ₜ rₜᵀ rₜ
    return background_term + obs_term


# user
def cost_gradient(adjoint: dfx.AbstractAdjoint) -> Float[Array, " n"]:
    def cost(state: Float[Array, " n"]) -> Float[Array, ""]:
        return window_cost(state, adjoint)

    # forward mode for ForwardMode and reverse mode otherwise
    differentiate = jax.jacfwd if isinstance(adjoint, dfx.ForwardMode) else jax.grad
    gradient_fn = differentiate(cost)
    # ∇𝒥(μ_x)
    return gradient_fn(background)  # (D_x,)


# today (diffrax)
adjoint_choices = [
    dfx.RecursiveCheckpointAdjoint(),
    dfx.BacksolveAdjoint(),
    dfx.DirectAdjoint(),
    dfx.ForwardMode(),
]
gradients = {type(adj).__name__: cost_gradient(adj) for adj in adjoint_choices}
reference = gradients["RecursiveCheckpointAdjoint"]  # (D_x,)
for name, gradient in gradients.items():
    print(name, bool(jnp.allclose(gradient, reference, atol=1e-4)))
```

Every adjoint prints `True`.

Disagreement is a bug. The most common causes are reverse-time instability in `BacksolveAdjoint` (switch to an implicit integrator) and under-converged optimisation in `ImplicitAdjoint` (tighten the tolerance).

## The shared strategy vocabulary

The same concepts recur at every layer, so the stack shares one declarative vocabulary: the frozen-dataclass specs in `pipekit_cycle.adjoints` (named after their diffrax counterparts). Each layer interprets a spec into its native mechanism, which is `pipekit_jax.to_diffrax_adjoint` at the dynamics layer, [`to_optimistix_adjoint`](xref:api#vardax.to_optimistix_adjoint) at the inner-solve layer (this chapter), and filterax's scan strategies at the cycle layer:

| Spec | dynamics (diffrax) | inner solve (optimistix / vardax) | cycle (filterax scan) |
|---|---|---|---|
| `DirectAdjoint` | `diffrax.DirectAdjoint` | unrolled (the default) | plain scan |
| `RecursiveCheckpointAdjoint` | `diffrax.RecursiveCheckpointAdjoint` | `optx.RecursiveCheckpointAdjoint` | checkpointed scan |
| `TruncatedAdjoint(k)` | none | [`KStepAdjoint(k)`](xref:api#vardax.KStepAdjoint), the deprecated alias of `argminax.adjoint.KStep(k)`; `k=1` ≡ `OneStep` | truncated scan |
| `ImplicitAdjoint` | steady-state only | `optx.ImplicitAdjoint` | none |
| `BacksolveAdjoint` | `diffrax.BacksolveAdjoint` ⚠ unstable for chaotic/stiff dynamics | none | none |

The spec `TruncatedAdjoint(k=3)` maps to `KStepAdjoint(k=3)`, which keeps the last three of the solver's $N_\text{iter}$ steps of [](#eq-4dvarnet-update) differentiable. The block continues the first one on the page.

```{code-block} python
:caption: Maps the `TruncatedAdjoint(k=3)` spec to `KStepAdjoint(k=3)` and runs the solver steps of [](#eq-4dvarnet-update) with it.
:label: code-adjoints-truncated
import pipekit_cycle as pkc

# Shapes: S = 2 windows; T = 3 steps, so T + 1 = 4 times; D_x = 8 state cells

# today (pipekit_cycle)
truncated_spec = pkc.adjoints.TruncatedAdjoint(k=3)
# today (vardax)
truncated_adjoint = vdx.adjoints.to_optimistix_adjoint(truncated_spec)
# today (vardax)
truncated_model = vdx.FourDVarNet1D(
    state_dim=8,
    n_time=4,
    latent_dim=8,
    hidden_dim=16,
    solver_adjoint=truncated_adjoint,
    key=key_net,
)
# x⋆ = x⁽N_iter⁾, the last three steps differentiable
truncated_reconstruction = truncated_model(batch)  # (S, T+1, D_x) → (S, T+1, D_x)
print(truncated_adjoint, truncated_reconstruction.shape)
```

It prints `KStepAdjoint(k=3) (2, 4, 8)`.

`KStepAdjoint` generalises the one-step strategy: at a converged fixed
point any $k$ is exact (the warmup contributes nothing); for the
truncated, unconverged solvers of 4DVarNet, larger $k$ trades memory
for a less biased gradient. The dynamics layer composes independently: the backward sweep through the forward run is `integrix.adjoint`'s (behind `checkpoint=`), and
a `pipekit_jax.DiffraxForwardModel` slots into
[`StrongFourDVar`](xref:api#vardax.StrongFourDVar) as a plain
`pipekit_cycle.ForwardModel`, bringing diffrax's solvers and adjoints
to the forecast step with no vardax code changes.

## Adjoint selection heuristics

| Scenario | Pick |
|---|---|
| Short window ($T \le 10$), default | `RecursiveCheckpointAdjoint()` |
| Long window ($T \ge 100$), memory-bound | `BacksolveAdjoint()` |
| Parameter estimation, $D_\theta \ll D_x$ | `ForwardMode()` |
| Debugging | `DirectAdjoint()` |
| Training `FourDVarNet`, memory-bound | `argminax.adjoint.OneStep()` |
| Training `FourDVarNet`, well-converged inner | `ImplicitAdjoint()` |
| Training `FourDVarNet`, default | `RecursiveCheckpointAdjoint()` |
| Training classical hyperparameters | `ImplicitAdjoint()` (always converged at MAP) |
