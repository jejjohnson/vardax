Notation

Every page and docstring uses the symbols below: the letter says what kind of object a symbol is, the subscript says which variable it belongs to, and a bold symbol is a vector or a matrix. Equations use x\vect{x}x in the documentation and Unicode, such as Σ_x|y, in docstrings and code comments.
